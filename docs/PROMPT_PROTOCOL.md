# Prompt and result protocol

The package and copy-prompt flows share the same reading depth, image safety rules, and image-generation workflow. Both complete the entire reading first, then derive private-data-free card copy and 3–5 visual motifs from facts actually calculated in the reading. Both require invoking ChatGPT's gpt-image image-generation tool to create one finished 1200×675 (16:9) card with the Japanese copy baked into the image. SVG, HTML/CSS, Canvas, Python, programmatic drawing, templates, and existing-image edits are not substitutes. If the image tool is unavailable, report that the image was not generated; do not fake a PNG.

The copy-prompt flow ends in ChatGPT: return the substantial Japanese reading directly in the conversation and show the generated card there. Do not produce JSON, a manifest, or a ZIP in this mode.

The request ZIP additionally requires the model to finish the reading and report, validate the complete result JSON against the embedded Draft 2020-12 schema, and only then create image content. All system collections, including `calculations`, are arrays. Its result ZIP contains `result.json`, `report.md`, `manifest.json`, and one generated finished card at `assets/share.png`. Record the actual generation tool/model and the source facts for the visual motifs in `assets.shareGeneration`; this record is an audit trail, not cryptographic proof.

No card may include a name, reading, alias, birth date/time, birthplace/current location, gender, contact details, or other identifying profile facts. The report cover is a fixed CSS design in landscape 3:2 and is not generated.

When a birth time is missing, mark only time-dependent components unavailable. Use a partial status and include reliable date/place-based calculations that remain possible. If a system truly cannot be calculated, keep its section in both JSON and report, explain why it is on hold, which input is missing, and what that input would unlock; do not leave an unexplained empty object or replace it with generic tradition text. For Jyotish, Nakshatra, and Dasha, distinguish date-based elements from Lagna/houses, boundary-sensitive lunar placement, and dasha start degrees that depend on time. Never invent placements.
