# Prompt protocol

The generated prompt combines core instructions, the subject record, selected questions and system names, and the output contract. It asks the model to distinguish historical traditions from modern esoteric systems, avoid filling missing birth data with guesses, state lineage and uncertainty, show calculations and sources, and discount correlated systems rather than treating them as independent votes. It also requires direct answers to every selected topic, concrete interpretations tied to each system's symbols, evidence-backed synthesis, and practical reflection without padding or deterministic predictions.

The ZIP result contract embeds `schema/result.schema.json` and requires the model to validate `result.json` against it before returning. All system collections, including `calculations`, must be arrays. The bundle must contain `result.json`, a substantial `report.md`, `manifest.json`, `assets/summary.png`, and `assets/share.png`. Keep exactly two images under `assets/`: `summary.png` at 1024×1536 (portrait 2:3) and `share.png` at 1200×675 (landscape 16:9). Set `result.json` references and `manifest.files` to those exact relative paths. Both files must be detailed AI-generated PNGs with the reading's specific symbolic motifs; SVGs and simple template cards are not substitutes. The share PNG is decorative artwork only, with no text or identifying details; the app overlays a personalized headline, short reading, and themes from the result JSON after removing the subject’s identity and birth data. The browser validates and displays both structured data and the full Markdown report.

The share card is rendered as a 1200×675 PNG. On devices supporting file sharing, the X action passes this PNG to the native share sheet, where X can be selected. On desktop browsers that cannot share files, it downloads the card and opens the X composer; the user attaches the downloaded image there.

Simple copy mode uses the same subject and content-quality instructions, but asks for a readable Japanese Markdown report directly in ChatGPT. It does not include the JSON, schema, ZIP, manifest, or image-file contract.
